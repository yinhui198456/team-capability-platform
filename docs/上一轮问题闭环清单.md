## 2. 自评与 Gap 流程已修正

**问题**：Assessment 状态机表述易误解为「Buddy 复核后才进入 Gap」。

**闭环动作**：

- 01_Product 6.1 明确：Gap 在 Member 提交自评后立即生成；Member 无需等待 Buddy 复核即可查看 Gap、设置优先级；Gap 正式纳入年度成长计划需在 Assessment Review 闭环后。
- 02_Design 6.1 Assessment 状态机：已复核状态的流转目标改为「完成该评估版本归档」，不再写「进入 Gap 分析与计划阶段」。
- 02_Design 6.1 增加「Gap 生成时点」说明：提交即生成；查看与优先级设置不阻塞，但纳入年度成长计划需 Assessment Review 闭环。
- 03_Data 3.12 Gap 业务定义补充「Member 提交自评后立即生成，无需等待 Buddy 复核」。
- 03_Data 5.1 Assessment 版本规则同步更新。
- 03_Data 追溯表新增「Member 提交自评后立即生成 Gap」条目。

- 03_Data 3.9 Assessment 关联关系：Assessment Review 改为 1:N。

- 03_Data 5.1 Assessment 版本规则：补充每次提交创建 Assessment Review、历史记录保留。
