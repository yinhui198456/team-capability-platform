# Issue #132 · 阶段 1 需求与验收矩阵

## 决策完整性

结论：**修改后接受**。

- 接受目标：让能力地图页面状态与可分享 URL 始终一致，并统一搜索、深链接、刷新、后退/前进和键盘操作。
- 修改既有方法：`docs/04_UI.md` 只规定初始 L3 Hash 定位；#132 要求将同一规则扩展到用户主动选择的 L1/L2/L3，并监听浏览器历史变化。
- 不采用静态图片或只修搜索点击：二者都无法完整覆盖状态恢复、键盘和无效深链接。
- 不修改业务模型、权限、接口、数据库或 #201；阶段 1 仅形成可评审交互合同。

## URL 合同

统一格式为 `/capability/model#<CODE>`；本静态原型以 `index.html#<CODE>` 等价演示。

| 状态 | URL | 页面结果 | 历史行为 |
|---|---|---|---|
| 默认入口 | 无 Hash | 默认显示 P01，不伪造一次用户选择 | 保留入口历史 |
| 选择 L1 | `#P02` | 选中并聚焦 P02 域概览 | 新增一条历史记录 |
| 选择 L2 | `#P02.02` | 选中 P02、展开并聚焦 P02.02 | 新增一条历史记录 |
| 选择 L3 | `#P02.02.08` | 选中 P02、展开 P02.02、聚焦并高亮 L3；搜索定位不自动打开 Drawer | 新增一条历史记录 |
| 刷新 | 保持当前 Hash | 从 URL 完整恢复当前层级 | 不新增历史记录 |
| 后退/前进 | 浏览器提供的 Hash | 恢复对应 L1/L2/L3 与展开、焦点状态 | 不重写历史 |
| 同页 Hash 变化 | 任一有效 Hash | 立即同步页面，不要求刷新 | 由浏览器历史驱动 |
| 可识别域的无效路径 | 如 `#P02.02.99` | 进入 P02，上方明确提示路径不存在；不冒充某个 L2/L3 已选中 | 保留问题 Hash 便于修复/分享 |
| 完全无效路径 | 如 `#NOT-A-CODE` | 不选中任何域，显示未找到和恢复动作 | 恢复动作清除无效 Hash |

## 范围边界

- 不把搜索查询、Drawer 开关或所选 P4～P8 职级写入 URL；它们不是可分享的能力路径。
- 不新增路由、API、权限、业务角色或数据对象。
- 不改变 L2“能力标准/职级要求”、L3“达成路径/学习实践项”的正式语义。
- 不把原型中的示例文本或数量反向定义为生产数据。
