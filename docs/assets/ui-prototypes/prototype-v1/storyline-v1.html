2. 四个动作的业务边界

它们不是四个全局页面阶段，而是每个 L3 可独立推进的状态变化。

动作 A

保存能力评级

  • 保存本次改动的任意若干项
  • 0 表示已评级；null 表示未评级
  • 不创建计划、任务或 Review
阻断范围：仅本次填写值是否合法
动作 B

选择提升项

  • 已评级且 Gap > 0 才可选择
  • 支持单选或多选
  • 其他未评级 L3 与本批次无关
阻断范围：仅所选项是否具备提升资格
动作 C

补充计划月份

  • 只填写一个年月字段
  • 整框点击即可打开年月面板
  • 与已选提升项一起保存为计划草稿
阻断范围：不阻断评级保存，只影响正式生成
动作 D

生成所选学习任务

  • 这是唯一创建任务的入口
  • 所选任一项缺月份则整批零写入
  • 重复提交复用已有任务
阻断范围：仅本次所选批次，批次内原子

5. TCP 轻量故事线模板

每条故事先走完这六步；第 5 步确认后，才进入逐页原型设计。

① 用户结果谁要完成什么，为什么有价值
② 角色与主干按时间顺序画端到端动作
③ 状态与规则输入、输出、约束、异常、幂等
④ 争议点确认只保留真实业务选择，不代替用户决定
⑤ 页面映射每个故事步骤对应入口、页面和主要动作
⑥ 原型与验证逐页低保真 → 核心路径串联 → UI/UX

7. 已确认的计划草稿规则

选择提升项和计划月份都属于可恢复草稿，不因退出页面或重新登录而丢失。

已确认

草稿保存

“已选择提升项 + 计划月份”持久保存；用户可以分多次完成，也可以取消尚未生成的选择。

正式生成边界

只有点击“生成所选学习任务”才创建正式计划和任务；保存评级、选择提升项、填写月份都不会偷偷生成任务。
