本阶段目标

先判断“需要哪些页面”，再讨论“页面长什么样”

页面不是按数据库表或角色名称堆出来的。每个页面必须承接一个明确用户动作；没有核心动作、与其他页面重复或只是筛选维度的页面，应当合并或移除。

页面取舍结果

11首批核心页面/详情页
4合并、内嵌或重新定义
4当前不规划的旧入口/页面
3第二批再做的支持页

4. 合并与删除建议

这些取舍直接解决当前“页面多、作用不清、左侧导航膨胀”的问题。

删除

Buddy 复核中心

它围绕已经取消的自评审核流程设计，不再承担任何活动业务。

成果相关操作统一进入：B01 成果验收
重新定义

旧“辅导成员看板”

原页面缺少清晰用途；保留“看成员进度”的真实需求，但不保留旧故事和旧布局。

重新定义为：D01 成员学习进度看板（Buddy / Leader 共用）
合并

评估历史

它是成长档案的一种历史数据，不需要占用一级业务入口。

合并到：M07 成长档案 → 评级历史页签
内嵌

Gap 摘要

Gap 是评级结果与筛选维度，不是一个完整业务流程。

放入：M02 顶部摘要、筛选和侧边详情
合并

用户 / 角色 / Buddy 关系

三者都围绕同一身份配置，拆成多页只会增加跳转。

合并为：A01 用户、角色与辅导关系
删除

整份自评提交

与逐项评级自动保存、显式任务生成冲突，也会制造虚假的全局完成门槛。

替换为：M02 评级自动保存 + 生成所选任务
不新增

独立通知中心

自学项目暂时没有足够通知量支撑新页面。

L3 变化直接显示在 M01、M04 和 M05
暂不规划

L02 年度能力重点

当前没有明确且高频的用户动作，先不为“规划”单独建设页面。

Leader 首批只保留：L01 团队能力分析
