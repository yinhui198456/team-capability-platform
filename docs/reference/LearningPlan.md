# 团队成员年度学习计划模板（参考文档）

> 来源：`capability-model/团队成员年度学习计划模板_基于能力模型_V1.3.xlsx`

> 说明：本文档忠实整理 Excel 内容，不新增业务规则。

## 1. 使用说明

### 1.1 模板用途

- **用途**：帮助团队成员基于能力模型识别需要补充的能力项，选择学习材料，制定 1 年周期、可跟踪、可验收的学习计划。

- **适用对象**：技术架构与开发专业线成员；当前能力模型覆盖 P01 Data Infra、P02 AI Infra / Agent、P03 Coding、C01 基本办公、C02 沟通协作、C03 学习创新。

- **核心原则**：以“三级能力项”为计划和跟踪的最小单元；学习结果应尽量有实操、Demo、脚本、配置截图、验证报告或可检查文档。

### 1.2 掌握度评分标准

| 掌握度 | 说明 | 职级参考 |
|---|---|---|
| 0 | 未接触 / 不具备可验证输出 | - |
| 1 | 了解概念，需要他人指导或协助 | 入门 |
| 2 | 标准场景可独立执行，有基础实操输出 | P4 |
| 3 | 能处理常见问题，能闭环基础异常 | P5 |
| 4 | 能设计方案、组织实施并处理复杂场景 | P6 |
| 5 | 能主导复杂项目，沉淀规范、模板和方法论 | P7-P8 |

### 1.3 填写流程

| 步骤 | 操作位置 | 填写 / 查看内容 | 结果 |
|---|---|---|---|
| 1 | 02_能力差距自评 | 填写当前掌握度、目标掌握度、优先级；将“是否纳入计划”选择为“是”。 | 选出年度需要补齐的能力范围。 |
| 2 | 03_年度学习计划 | 自动拉取 02 中入选能力项；手填计划开始、计划截止、目标月份等计划信息。 | 形成年度学习计划清单。 |
| 3 | 04_学习执行跟踪 | 自动同步 03 的计划项；维护执行状态、实际开始 / 完成、实际耗时、证据链接、完成质量、复盘结论和下步动作。 | 形成学习执行记录和年度成长档案。 |
| 4 | 05_月度复盘 | 按月查看计划数、完成数、完成率、耗时和复盘记录。 | 形成月度复盘与改进闭环。 |

### 1.4 02 → 03 → 04 的关系

- **02_能力差距自评**：选择需要补齐的三级能力项；不在 02 中写详细执行记录。

- **03_年度学习计划**：自动生成年度计划清单；用于安排年度 / 季度 / 月度节奏。

- **04_学习执行跟踪**：与 03 一对一同步，不再拆分更细任务；用于记录执行状态、证据、完成质量和复盘结论。

### 1.5 完成判定

- 一条学习计划建议同时满足：状态为「已完成」、有证据链接或文件说明、有复盘结论。

- 如未产出可检查材料，不建议判定为完成。

- 先尽量固定 02/03 年度计划范围，再进入 04 跟踪执行；中途大幅调整 02 的入选范围时，需复核 04 中手填状态和证据是否仍对应正确能力项。
