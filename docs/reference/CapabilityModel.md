## 1. 模型总览

> 技术架构与开发专业线能力胜任模型 V1.0（简洁版）

| 项目 | 内容 |
|---|---|
| 模型用途 | 职级晋升评审、技术人员能力盘点、培训课程体系建设 |
| 适用对象 | 技术架构与开发专业线下的综合型技术角色；团队规模 < 10 人，采用统一综合模型 |
| 人才画像 | 平台型技术专家 + 解决方案架构师 |
| 能力结构 | 专业能力 70% + 通用素质能力 30%；专业能力内部暂不拆分权重 |
| 核心产品范围 | Data Infra：TDC、TDH、ArgoDB、TDS；AI Infra：LLMOPS、问数 |
| P4 入门抓手 | TDH / TDC 安装部署大赛能力包；AI Coding 入门包（SDD、TDD、AI辅助编码） |

### 模型维度统计

|---|---|---|---|---|
| 6 | 3 | 5 | 6 | 3 |

### 使用建议

使用建议：先用于管理层讨论与能力盘点；稳定后再补充二级考核项、评分标准、证据权重和课程学时。

## 5. 评审使用说明与后续细化建议
