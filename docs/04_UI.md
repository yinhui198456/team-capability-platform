# 04 UI

## 1. 文档目标与边界

本文档将 `01_Product`、`02_Design`、`03_Data` 转化为页面规格，作为后续原型开发与验收依据。

- 适用范围：技术架构与开发专业线、单团队、少于 10 人。
- 启用能力域：P01 Data Infra、P02 AI Infra / Agent、P03 Coding、C01 基本办公、C02 沟通协作、C03 学习创新。
- 页面定位：内部 Web 运营工作台；不建设 LMS、绩效评审、独立消息中心、综合总分。
- 角色：Member、Buddy、Leader、Admin；权限与数据范围按有效角色叠加。
- 视觉基线：已确认的 5 张原型图。采用深蓝顶部导航、浅灰蓝工作区、白色卡片、紧凑表格和蓝/绿/橙/红状态标签。

## 3. 通用交互与状态规范

### 3.1 通用组件

| 组件 | 规则 |
|---|---|
| 状态标签 | 未开始/进行中/待 Evidence Review/已完成/延期/暂停/取消；用文字加颜色共同表达 |
| Evidence 版本 | 显示版本号、提交时间、提交人、Review 结论；历史版本只读，不回流 |
| Review 面板 | 固定显示关联 Member、L3、依据、历史、结论与反馈；结论提交后归入历史 |
| 时间与范围筛选 | 年度、成员、能力域、状态；默认值与角色数据范围一致 |
| 空态 | 明确说明“暂无待办/暂无计划/暂无权限”，给出可执行入口或返回路径 |
| 首页提醒 | 仅在看板展示待提交 Evidence、待复核、计划到期、任务延期；不建设独立消息中心 |

### 3.2 指标口径

| 指标 | 口径 |
|---|---|
| Gap | 目标掌握度 − 当前掌握度 |
| 能力实际值 | 当前掌握度按能力域聚合后的均值 |
| 能力计划值 | 目标掌握度按能力域聚合后的均值 |
| 成员能力达成率 | 当前掌握度 ÷ 目标掌握度 × 100%；目标为 0 时显示 `N/A`；允许大于 100% |
| 年度计划进度 | 计划项按未开始、进行中、待 Evidence Review、已完成、延期、暂停、取消统计 |
| 延期计划项 | 当前日期晚于计划截止日期，且状态不是已完成或取消的计划项 |
| 当月计划完成数 | 目标月份或计划截止日期落在当月的计划项数 |
| 当月实际完成数 | 实际完成日期落在当月且状态为已完成的学习任务数 |
| 累计计划完成率 | 截至当月应完成计划项数 ÷ 年度计划项总数 |
| 累计实际完成率 | 截至当月实际已完成计划项数 ÷ 年度计划项总数 |
| 全年计划时长 | 年度成长计划内计划项预计耗时之和 |
| 全年累计时长 | 年度内学习执行日志实际时长之和 |
| 当月计划时长 | 目标月份落在当月的计划项预计耗时之和 |
| 当月累计时长 | 学习执行日志记录日期落在当月的实际时长之和 |

### 3.3 数据补充要求

学习时长来自 `03_Data` 已定义的 **Learning Progress Log（学习执行日志）**：

- 固定字段为 `task_id`、`record_date`、`actual_hours`、`note`、`recorder`；每条日志关联一个 Learning Task。
- 日志仅用于按 `record_date` 聚合学习时长，不拆分计划项或学习任务，不改变“一计划项对应一学习任务”的 MVP 规则。
- Member 可新增或编辑本人日志；Buddy、Leader 按负责成员 / 团队范围查看；Admin 全量查看。

视觉核对备注：已逐一核对 `docs/assets/ui-prototypes/UI-01..UI-05` 实际 PNG；五张图的布局要素与本节映射一致，未发现需静默假设的视觉差异。学习执行日志不新增独立页面，继续在 UI-01、UI-03 及月度复盘的既有区域呈现。

### 3.4 能力项名称显示规则

L3 能力项在列表、卡片、抽屉、详情中统一按“名称优先、代码辅助”展示，推荐格式为：**`{l3_name}（{l3_code}）`**。

| 场景 | 展示格式 | 回退规则 |
|---|---|---|
| 计划项卡片/列表 | `{l3_name}（{l3_code}）` | `l3_name` 为空时显示 `{l3_code}` |
| 学习任务卡片 | `{l3_name}（{l3_code}）` | 同上 |
| Evidence / Review 关联 L3 | `{l3_name}（{l3_code}）` | 同上 |
| Gap 概览 | `{l3_name}（{l3_code}）` | 同上 |

## 4. 关键页面规格

### 4.1 我的成长看板

**页面目标：** Member 快速了解年度计划执行、能力差距、当前学习任务和待办。

**对应视觉原型：** UI-01。验收时重点核对三组布局：计划执行、能力分析、学习执行；不得恢复已取消的能力域覆盖、重点提升建议等模块。

| 区域 | 展示内容 | 操作与联动 |
|---|---|---|
| 年度计划进度 | 整体进度环；计划项、已完成、进行中、未开始、延期数量 | 点击状态进入年度成长计划并带入状态筛选；延期用红/橙标签突出 |
| 学习时长 | 全年累计时长、全年计划时长、当月累计时长、当月计划时长 | 点击进入月度复盘或学习任务；数据来自计划项与学习执行日志 |
| 待办事项 | 待提交 Evidence、待 Buddy 复核、计划到期、学习任务延期 | 点击进入相应列表并自动筛选 |
| 能力分析 | 能力域筛选器、个人能力雷达图、Gap 概览 | 见下方联动规则 |
| 当前学习任务 | 任务名称、所属能力域/L3、计划月份、预计/实际时长、进度、状态 | 点击进入学习任务详情；仅显示未完成、待 Review、延期任务 |

**能力雷达图与 Gap 联动：**

1. 默认选择“全部”，雷达图展示六个能力域，Gap 概览展示全部 L3 差距；
2. 点击雷达图某一能力域或顶部能力域筛选项后，Gap 概览仅展示该能力域的 L3；
3. Gap 概览字段：能力域/L3、当前掌握度、目标掌握度、Gap、优先级；
4. 提示文字：`选择能力域查看对应 Gap`；
5. 看板仅展示已启用的六个能力域。

**不展示：** 能力域覆盖卡片、重点提升建议、综合总分、独立消息中心。

#### 4.1.1 动态阶段与主按钮

Member 工作台根据当前年度 assessment 与年度计划状态动态展示：

| 阶段 | 触发条件 | 页面主标题 | 主按钮 | 展示内容 | 隐藏内容 |
|---|---|---|---|---|---|
| 待完成自评 | 无年度 assessment，或最新 assessment 为 `草稿` | 完成能力自评 | 完成能力自评 → `/capability/assessment` | 自评引导卡片 | 计划进度、学习时长、待办、雷达/Gap、任务 |
| 待复核 | 最新 assessment 为 `待复核` 或 `建议调整` | 自评已提交 | 查看自评 → `/capability/assessment` | 复核状态、Gap 概览 | 计划进度、学习时长、待办、当前任务 |
| 待制定计划 | assessment 已复核/已归档，但年度 plan 尚未创建 | 准备生成年度计划 | 生成年度计划 → `/growth/annual-plan` | 生成年度计划引导 | 计划进度、学习时长、待办、当前任务 |
| 计划执行中 | 年度计划为 `制定中` 或 `执行中` | 我的成长总览 | 查看年度计划 → `/growth/annual-plan` | 年度计划进度、学习时长、待办、雷达/Gap、当前学习任务 | 无 |
| 年度已归档 | 年度计划状态为 `已归档` | 年度成长总结 | 查看成长档案 → `/growth/profile` | 年度总结、成长档案入口 | 待办事项、当前学习任务 |

顶部统一显示：年度、`数据范围：本人`、当前阶段标签。

### 4.2 能力自评与 Gap 分析

**页面目标：** Member 完成 L3 自评，提交后查看 Gap、设置优先级；最新一次自评 Review 认可闭环后，才可正式纳入年度计划。

**对应视觉原型：** UI-02。验收时重点核对 L3 表格层级、Gap 侧栏和“Review 闭环前不可正式纳入计划”的状态提示。

| 区域 | 展示内容 | 操作 |
|---|---|---|
| 评估头部 | 年度、评估版本、自评进度、最新 Review 状态 | 保存草稿、提交自评、查看评估历史 |
| 能力项表格 | L1/L2/L3 层级；当前掌握度、目标掌握度、Gap、优先级、自评依据、状态 | 展开/收起、填写分值与依据、按能力域筛选 |
| 自评依据 | 文件/链接、完成场景、备注 | 查看、添加、删除草稿附件 |
| Gap 侧栏 | Gap 总数、均值、高优先级项、分布 | 查看详情、筛选高优先级项 |
| 纳入年度计划 | 最新 Review 认可闭环前显示禁用状态及原因；闭环后可选择 Gap 项纳入计划 | 勾选“是否纳入计划”，进入成长目标/年度成长计划 |

**关键规则：**

- 提交自评后立即生成 Gap，可查看、筛选和设置优先级；
- Buddy 的建议调整不阻塞查看 Gap；
- 正式将 Gap 纳入年度成长计划（包括生成年度成长计划及其计划项）的统一门禁：当前 Assessment 最新一次提交对应的 Assessment Review 已闭环，Review 结论为「认可」，且不存在待复核事项。
- 不显示未来扩展域。

### 4.3 年度成长计划与学习任务

**页面目标：** 管理个人年度计划、L3 计划项、学习任务执行与 Evidence 版本。

**对应视觉原型：** UI-03。验收时重点核对计划项列表、月度时间轴、任务详情抽屉、Evidence 版本历史和延期状态。

| 区域 | 展示内容 | 操作 |
|---|---|---|
| 年度总览 | 年度、计划周期、总体进度、计划项状态统计、预计/实际时长 | 切换年度、查看月度复盘 |
| 计划项列表 | L3 能力项名称（`l3_code`）、目标掌握度、学习任务/实操内容、预期输出、计划月份、预计/实际时长、状态 | 筛选、查看详情、调整计划日期/目标月份、暂停/恢复/取消 |
| 月度时间轴 | 1–12 月计划分布与状态 | 选择月份筛选计划项 |
| 学习任务详情 | 执行记录、实际开始/完成日期、实际耗时、复盘结论、下步动作 | 更新进度、填写执行日志、提交 Evidence |
| Evidence 版本 | 版本号、提交内容、链接/文件、提交时间、Review 状态与反馈 | 新建草稿、提交、查看历史；历史版本只读 |

**状态规则：**

- 一个 Plan Item 对应一个 Learning Task，不支持子任务拆分；
- 任务提交 Evidence 后进入“待 Evidence Review”；
- Evidence 通过后，任务与计划项可完成；需补充或驳回时创建新的 Evidence 版本；
- 到期未完成的计划项/任务显示“延期”，并进入首页与团队分析的延期明细。

### 4.4 Buddy 复核中心

**页面目标：** Buddy 对负责成员的自评和 Evidence 提供辅导性复核与反馈。

**对应视觉原型：** UI-04。验收时重点核对“全部成员/单个成员”选择与复核队列联动，以及复核工作区的依据、历史、结论和反馈。

| 区域 | 展示内容 | 操作与联动 |
|---|---|---|
| 顶部统计 | 辅导成员、待复核自评、待 Review Evidence、需跟进 | 点击进入对应队列筛选 |
| 我的辅导成员 | `全部成员` + 成员列表；进度、待复核数量 | 默认选中“全部成员”；选择具体成员时联动复核队列 |
| 复核队列 | 全部待复核、自评复核、Evidence Review 三个标签；成员、类型、L3、提交时间、优先级/状态 | 默认显示全部成员待办；按左侧成员和标签联合筛选 |
| 复核工作区 | 成员、L3、当前/目标掌握度、Gap、自评依据或 Evidence 版本、历史反馈 | 填写反馈并提交结论 |
| 反馈历史 | Assessment Review、Evidence Review 的闭环历史 | 仅查看，不重新流转 |

**结论与文案：**

- 自评复核：`认可`、`建议调整`；
- Evidence Review：`通过`、`需补充`、`驳回`；
- 使用“复核、Review、反馈、建议”表述，不使用行政审批语义。

### 4.5 团队能力分析

**页面目标：** Leader 从实际与计划、执行进度和学习投入三个维度查看单团队运营情况，不直接编辑成员数据。

**对应视觉原型：** UI-05。验收时重点核对四项核心图表和延期明细，不得恢复已删除的雷达图、Gap 分布、优先级或泛化建议模块。

| 区域 | 展示内容 | 口径与操作 |
|---|---|---|
| 筛选与 KPI | 年度、成员、能力域；自评完成率、计划完成率、Evidence 通过率、延期计划项 | 默认全团队；筛选后所有图表联动 |
| 能力实际 vs 计划 | 六个能力域的当前掌握度均值与目标掌握度均值分组对比图 | 显示实际值、计划值；不计算综合总分 |
| 成员能力达成率 | 成员 × 六个能力域的百分制热力表 | 当前掌握度 ÷ 目标掌握度 × 100%，允许超过 100% |
| 计划完成趋势 | 1–12 月组合图 | 柱：当月计划完成数/当月实际完成数；线：累计计划完成率/累计实际完成率 |
| 学习时长趋势 | 1–12 月组合图 | 柱：当月计划时长/当月实际时长；线：累计计划时长/累计实际时长，单位小时 |
| 延期计划项明细 | 成员、L3、计划截止日期、延期天数、状态 | 点击进入只读计划项详情 |

**不展示：** 团队能力雷达图、能力域 Gap 分布、年度能力建设优先级、下一年度能力建设重点、泛化建议模块。

## 5. 次要页面规格

| 页面 | 主要内容 | 关键操作 |
|---|---|---|
| 能力模型 | L1/L2/L3、等级描述、学习资源关联、启用状态 | Leader 维护与导入导出；扩展域仅显示占位 |
| 评估历史 | Assessment 版本、提交时间、Review 结论、能力变化 | 查看快照与历史反馈 |
| 成长目标 | 已纳入计划的 Gap、目标掌握度、优先级 | 确认后归入年度成长计划 |
| 月度复盘 | 当月计划/实际完成、预计/实际时长、主要产出、问题、下月重点 | Member 填写；Buddy/Leader 按范围查看 |
| 成长档案 | 年度评估、计划、任务、通过的 Evidence、Review 历史 | 按年度查看和导出（如后续开放） |
| 学习资源 | 材料编码、名称、类型、链接、用途、状态、关联 L3 | Leader 维护 |
| 团队年度能力规划 | 年度、重点能力域、资源安排、说明、状态 | Leader 发布与归档 |
| 用户管理 | 用户、职级、团队、账号状态、主 Buddy、角色 | Admin 维护 |
| 角色权限 | 固定角色、权限项、数据范围 | Admin 分配；不新增业务角色 |
| 系统配置 | 年度评估窗口、首页待办展示规则、默认计划周期 | Admin 维护 |

## 6. 页面验收清单

| 验收项 | 通过标准 |
|---|---|
| 业务一致性 | 页面对象、字段、状态、权限均能追溯到 01～03 |

## 7. 与后续开发的衔接

进入开发前需完成：
